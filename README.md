| ファイル | 内容 |

## OKANE 収益化ナビでできること

- **収益化ゲージ**：YouTube（拡充版・広告）、X、TikTok、Instagram の条件に対して、自分の数字があとどれだけ足りないかを表示
- **投稿計画**：ジャンルと読んでほしい人を入れると、今日から30日分の投稿テーマ表を作成（テキストでコピー可）
- **ネタ帳**：伸びやすい型で投稿タイトルを30本作成
- **収益試算**：広告・アフィリエイト・note の月収と、確定申告が必要になりそうかの目安
- **守ること**：ステマ規制、税金、詐欺、個人情報などのチェックリスト

入力した数字はそのブラウザの中だけに保存され、どこにも送信されません。

## 使い方

1. `app/index.html` をダウンロードしてブラウザで開く（スマホでもパソコンでも可）
2. 「収益化ゲージ」で使うSNSを選び、アプリの分析画面に出ている自分の数字を入れる
3. 「投稿計画」で30日分のテーマ表を作り、そのとおりに投稿する

## 注意

- アカウントの作成、本人確認、口座の登録、投稿は本人が行う必要があります。
- 収入を約束するものではありません。各SNSの条件は予告なく変わるので、申し込む前に必ず公式の画面で確かめてください。
