# SNSで稼ぐためのガイド（2026年10月12日時点）

このガイドは、SNSでお金を稼ぎたい人が「何から、どの順番で、何に気をつけて」進めればよいかをまとめたものです。
各SNSの条件は公式ヘルプ・公式発表・報道で確認しました。確認できなかったものは「未確認」と書いています。
条件は予告なく変わるので、申し込む前に必ず各アプリの画面で確かめてください。

## 最初に知っておくこと

- **人数の条件なしで今日から始められる稼ぎ方**と、**フォロワーや再生数の条件を満たさないと受け取れない稼ぎ方**があります。
  - 今日から：note の有料記事・メンバーシップ、アフィリエイト（紹介リンク）、自分の商品やサービスの販売
  - 条件あり：YouTube の広告収益、X のオリジナルコンテンツ報酬、TikTok の Creator Rewards Program、Instagram のギフト など
- おすすめの進め方は「メインのSNSを1つ決めて育てる」＋「note やアフィリエイトでお金の入口を先に作る」です。
- 「誰でも簡単に」「いいねを押すだけで」稼げる話は詐欺の可能性が高いです（下の「お金を守る」を参照）。

## 各SNSの収益化の条件

### YouTube

| 段階 | 条件 | 受け取れるもの |
| --- | --- | --- |
| 拡充版 | 登録者500人以上＋直近90日に公開動画3本以上＋（直近12か月の総再生時間3,000時間以上 **または** 直近90日のショート視聴回数300万回以上） | メンバーシップ、Super Thanks などのファンからの支援、ショッピング |
| 広告収益 | 登録者1,000人以上＋（直近12か月の総再生時間4,000時間以上 **または** 直近90日のショート視聴回数1,000万回以上） | 広告収益の分配 |

- 共通：2段階認証、コミュニティガイドライン違反の警告がないこと、AdSense アカウント（18歳未満は保護者のもの）。
- **2027年2月1日から新しく申し込む人**は、広告収益の条件が「総再生時間8,000時間（直近365日）」または「ショート2,000万回（直近90日）」に引き上げられると、2026年8月10日に発表されています。
- 出典：[YouTube ヘルプ：拡充版 YouTube パートナー プログラムの概要](https://support.google.com/youtube/answer/13429240?hl=ja)、[YouTube ヘルプ：YouTube パートナー プログラムの概要と利用資格](https://support.google.com/youtube/answer/72851?hl=ja)、[Tubefilter（2026年8月10日）](https://www.tubefilter.com/2026/08/10/youtube-partner-program-ad-eligibility-requirements-shorts/)

### X（旧Twitter）

**旧「クリエイター広告収益分配プログラム」は2026年9月7日で終了しました。** 9月8日からは「オリジナルコンテンツ報酬（Original Content Rewards）」に変わっています。日本も対象国です。

- 18歳以上
- X Premium、Premium+、Premium Business のいずれかに加入
- 認証済みフォロワー500人以上
- 直近90日で、認証済みユーザーからのホームタイムライン上の表示が50万回以上（返信で得た表示は数えない）
- オリジナルの投稿を続けていること。他人の素材に一言添えただけ、画像に文字を載せただけ、他のSNSからの転載はオリジナルと見なされない
- 日本からの受け取りは Stripe で本人確認と口座登録。支払いは2週間ごと、最低30ドルから
- 旧制度の参加者も自動では移らず、改めて申し込みが必要
- 出典：[X ヘルプセンター：Original Content Rewards](https://help.x.com/en/using-x/original-content-rewards)、[Impress Watch](https://www.watch.impress.co.jp/docs/news/2131768.html)、[テクノエッジ（2026年8月9日）](https://www.techno-edge.net/article/2026/08/09/5375.html)

### TikTok（Creator Rewards Program）

- 18歳以上
- フォロワー1万人以上
- 動画視聴数10万回以上（解説記事では「直近30日」とされることが多いが、公式発表の文には期間がない。アプリ内の表示を優先）
- 個人アカウント（ビジネスアカウントは対象外）
- 報酬の対象は1分以上のオリジナル動画
- 公式発表は「参加条件は今後変更する可能性がある」としています
- 出典：[TikTok Newsroom：Creator Rewards Program を開始（2024年3月）](https://newsroom.tiktok.com/ja-jp/tiktok-creator-rewards-program)

### Instagram（リールのギフト）

- プロアカウント（クリエイターかビジネス）、18歳以上、パートナー収益化ポリシーを守っていること
- フォロワーは2023年11月の日本導入時の発表で5,000人以上。その後500人に下がったという報道もあるが、**公式には未確認**
- 出典：[Meta：クリエイターの収益化ツールを強化（2023年11月）](https://about.fb.com/ja/news/2023/11/giving-more-creators-around-the-world-ways-to-earn-money/)

### Threads

- 2024年に招待制の「Threads ボーナス」がテストされましたが、2026年時点で日本で誰でも使える直接の収益化制度は**確認できませんでした**。

### note（人数の条件なし）

- 有料記事・マガジン・チップ・メンバーシップは誰でも始められます。メンバーシップの開設は無料。
- 手数料：決済手数料（クレジットカード5%、PayPay 7%、PayPal 6.5%、携帯キャリア決済15%）を引いた残りから、プラットフォーム利用料（有料記事・マガジン・チップ・メンバーシップ10%、定期購読マガジン20%）。振込ごとに270円。
- 例：1,000円の記事がカードで1本売れると、手数料145円＋振込手数料270円で、振込額は585円。
- 出典：[note ヘルプ：コンテンツを販売する際に引かれる手数料](https://www.help-note.com/hc/ja/articles/360011358873)

### アフィリエイト（紹介リンク）

- Amazon アソシエイトなどの紹介リンクから買われると紹介料が入ります。
- 2026年4月20日付の規約改定で、SNSの**有料広告**（ブースト広告を含む、お金を払って配信した投稿）に貼った Amazon.co.jp へのリンクは紹介料の対象外になったと報じられています（[ネットショップ担当者フォーラム](https://netshop.impress.co.jp/n/2026/04/16/15928)、[INTERNET Watch](https://internet.watch.impress.co.jp/docs/yajiuma/2102119.html)）。お金を払っていない普通の投稿は対象外になっていません。正確な条件は規約の原文で確認してください。
- 紹介する投稿には「PR」「広告」と分かる表記を入れてください（次の章）。

## 法律とお金のルール

### ステルスマーケティング規制（景品表示法）

- 2023年10月1日から、広告なのに広告と分からない表示（ステマ）は景品表示法の規制対象です（令和5年内閣府告示第19号）。
- 主に責任を問われるのは依頼した企業ですが、企業は投稿者に表記を求めます。案件やアフィリエイトの投稿には「PR」「広告」「プロモーション」などと分かるように書きましょう。
- 出典：[消費者庁](https://www.caa.go.jp/)（「ステルスマーケティング」で検索）、[Web担当者Forum（2023年3月29日）](https://webtan.impress.co.jp/n/2023/03/29/44572)

### 税金（確定申告）

- 会社員・パートで年末調整を受けている人は、副業などの所得（収入−経費）が年20万円を超えると所得税の確定申告が必要です。
- 20万円以下でも、住民税の申告は必要です（住民税には20万円の基準がない）。
- 医療費控除などで確定申告をする年は、20万円以下の副業所得も含めて申告します。
- 給与のない人（学生・フリーランスなど）は基準が違います。国税庁の「確定申告書等作成コーナー」か税務署で確かめてください。
- 毎月の収入と経費をメモし、領収書と各SNSの支払い明細を保存しておきましょう。
- 出典：[国税庁 No.1900 給与所得者で確定申告が必要な人](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1900.htm)、[国税庁 No.1900 Q&A](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1900_qa.htm)

## お金を守る（詐欺に注意）

- 国民生活センターは2026年5月19日、「いいねを押すだけ」「スタンプを送るだけ」「スクリーンショットを撮るだけ」で稼げるとうたう副業で、お金をだまし取られる被害について注意を呼びかけました。最初に少額の報酬を払い、その後「高額報酬のタスクのため」などと高額の振り込みを求める手口です。
- 「誰でも簡単に月100万円」のような高額な情報商材・塾・コンサルに、借金してまで払わないでください。
- 困ったら：消費者ホットライン **188**、警察相談専用電話 **#9110**
- 出典：[国民生活センター：儲け話に関するトラブルにご注意！](https://www.kokusen.go.jp/soudan_now/data/moukebanashi.html)、[INTERNET Watch（2026年5月）](https://internet.watch.impress.co.jp/docs/news/2110126.html)

## はじめの90日の進め方

1. **SNSを1つとジャンルを1つ決める。** 「自分が続けられること」と「見たい人がいること」が重なるテーマにします。
2. **プロフィールを整える。** 「誰の、何の役に立つアカウントか」を1行で書きます。
3. **30日間、計画どおりに投稿する。** `app/index.html` の「投稿計画」タブで30日分のテーマ表を作れます。
4. **数字を見て直す。** 休みの日に、反応がよかった投稿の型（教える・共感・記録など）を確かめ、次の30日に多めに入れます。
5. **お金の入口を作る。** 反応がよかったテーマをまとめて note の有料記事にする、実際に使っている物をPR表記つきで紹介する、など。
6. **条件に届いたら申し込む。** 「収益化ゲージ」タブで進み具合を確かめます。

## このガイドでできないこと

- アカウントの作成、本人確認、口座の登録、投稿そのものは、本人にしかできません。
- このガイドとツールは収入を約束しません。
